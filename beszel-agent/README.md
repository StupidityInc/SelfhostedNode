# beszel-agent/

Compose template and `.env.example` for the Beszel **agent**.

This directory is the **template source**. The runtime stack at
`/opt/stacks/beszel-agent/` is deployed by `addons/beszel-agent/install.sh`
(WP5). Until WP5 lands, `bootstrap.sh` installs the agent inline and
copies these files directly.

## Files

- `docker-compose.yml` — Beszel agent service. Uses host networking
  for host statistics; listens on `127.0.0.1:45876`; disables SSH mode;
  publishes no Docker ports; does not require any UFW rule.
- `.env.example` — reference template for operators. The runtime
  `.env` is generated by the installer (root-owned, mode 600) and is
  intentionally inside `/opt/stacks/` so it is included in the
  encrypted restic backup. Never commit the real `.env`.

## What is NOT here

- The hub (Beszel server). Install that manually on the monitoring
  node, commonly under `/opt/stacks/beszel/`. Keep its UI reachable
  through Tailscale only.
- Uptime Kuma. Also manual, on the monitoring node only.

## Installer

`addons/beszel-agent/install.sh` (currently a stub) deploys this
template at install time. Behaviour must match the current inline
implementation in `bootstrap.sh:configure_beszel_agent`. See AGENT.md
§3 WP5 for the contract.
